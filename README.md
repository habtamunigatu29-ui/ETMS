# Ethio Telecom Apprenticeship Management System (ET-AMS)

## Start locally on Windows

Do not open `index.html` directly. ET-AMS requires its Vite and Express server.

1. Configure `DATABASE_URL` and `JWT_SECRET` in `.env`.
2. Double-click `start.bat`, or run `npm.cmd run dev` from this folder.
3. Open the URL printed in the terminal (normally `http://localhost:3000`).

`start.bat` installs dependencies when `node_modules` is absent. Node.js 20 or later and a reachable MySQL database are required.
